# data · 数据文件

> ⚠️ **本目录下的数据文件不进 git**（见根目录 `.gitignore`）。
> 原因：公开的原始数据文件常达数十上百 MB，GitHub 单文件上限 100MB，且大文件一旦进入 git 历史便无法回落。
> **替代方案：本 README 记录获取方式，他人 clone 后照此下载即可完整复现。**

## ③ 自建数据（`generated/`）

本项目可能需要自建部分数据（公开数据通常不覆盖全部业务对象）。

> ⏳ 具体自建范围**待数据源确定后再定**。

### ⚠️ 若涉及库存 / 进销存，必须满足台账平衡

```
期初库存
  + Σ入库
  − Σ出库
  − Σ报损
  ± Σ盘盈亏
  = 期末库存
```

且**出库量必须由业务单据（如订单 × 配方）算出，不得凭空生成**——否则台账对不上，后续的预测与补货也就失去了因果依据。

## ④ 下载后的操作

1. 把文件放入 `raw/`，**不要改名**（改名后校验值无法比对）
2. 计算校验值并回填到登记表：
   ```powershell
   Get-FileHash .\raw\<file> -Algorithm SHA256
   ```
3. 记录下载日期与来源
