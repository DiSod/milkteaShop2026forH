## 本周关键决策

| 决策 | 结论 | 理由 |
|---|---|---|
| 经营场景 | **奶茶店（单店）** | 结构完备：商品 ↔ 库存之间隔着配方（BOM） |
| 数据策略 | **母本 + 自建** | 公开数据中不存在单店奶茶的库存/进货记录 |
| 数据源 | ⏳ **待定** | 候选调研见 `data-availability.md` |
| 复杂度控制 | 原料 ≤ 60 种、菜单 ≤ 30 款、不接外卖平台 | 对应"不要太复杂" |
