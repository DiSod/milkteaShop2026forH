# weeks · 过程域

17 周的过程记录与阶段提交。

## 放什么 / 不放什么

| ✅ 放这里 | ❌ 不放这里 |
|---|---|
| 每周的产出：周报、探索脚本、设计草稿 | 最终版 SQL（→ `project/sql/`） |
| 周次索引与进度 | 完整业务文档（→ `project/docs/`） |
| 阶段提交快照（`submissions/`） | 规范与 AI 记录（→ `harness/`） |

## 核心规矩：草稿 → 正式 的升级路径

```
weeks/weekNN/ 草稿脚本
      │  验证通过、纳入正式流程
      ▼
project/sql/NN-xxx/ 正式脚本
      │
      ▼
在 weeks/weekNN/README.md 留一行：
      "本周产出的 xxx.sql 已并入 project/sql/01-schema/"
```

> 保留过程痕迹，同时避免出现两份各自演化的 SQL。
