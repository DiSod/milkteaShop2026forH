# submissions · 阶段提交归档

四次阶段作业的**提交快照**。每个版本目录在提交截止时冻结一份，之后不回改。

> 归档的意义：课程要求"每个阶段结束后提交一个能够运行和复现的项目版本"。快照让"当时提交了什么"可追溯——这在后续答辩与组内复盘时是关键证据。

## 归档内容（每次提交）

课程《提交作业要求》规定的内容：

| # | 提交物 | 说明 |
|---|---|---|
| 1 | `README.md` | 项目范围、环境、整体链路与复现步骤 |
| 2 | `code/` | SQL 语句与具体代码（提交时的 `project/sql/` 快照） |
| 3 | `report.md` | 阶段报告：设计思路、实验过程、实验总结 |
| 4 | `ai-usage.md` | AI 使用记录：如何使用 AI 协助，AI 输出与人工修改内容 |
| 5 | `contributions.md` | 组内分工表：成员分工与贡献 |

## 归档规则

1. 提交截止**前**从 `project/` 与 `weeks/` 复制快照，**不要**在 `submissions/` 里直接开发
2. 归档后该目录**不再修改**
3. `ai-usage.md` 与 `contributions.md` 汇总该阶段全部周度的记录
