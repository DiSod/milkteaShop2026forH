## 0. 任务与硬约束

| 项 | 要求 |
|---|---|
| 用途 | 数据库课程实验 **第二阶段 v1.0** 的课堂汇报 |
| 时长 | **5—6 分钟**（10 页，含 2 页现场演示页；演示页只放静态截图，实际操作由讲者切到浏览器） |
| 比例 | 16:9（1920×1080 或 13.33×7.5 英寸） |
| 页数 | **恰好 10 页** |
| 语言 | 简体中文；技术名词保留英文（CHECK / BCNF / TOCTOU 等） |
| 观众 | 课程老师 + 同学；**多数人不懂本项目细节** |
| 讲者 | 1 人（DiSod），讲稿见 [`presentation-script.md`](presentation-script.md) |

**五条不能违反的规则**

1. **数字只能取本文件的**。本文件没写的数字，一律不要出现在页面上。
2. **不要生成"示意图"代替截图**。每页指定的图都在仓库里，直接引用。
3. **每页正文要点不超过 3 条**，每条不超过 20 个汉字。讲不完的内容放讲者备注，不放页面。
4. **不要堆 bullet 墙**。本套 PPT 的信息密度靠"一个大数字 + 一张图 + 一句话"撑起来。
5. **不许写"我们非常荣幸""本次汇报将……"这类开场套话**。第一页第一句就讲事实。

## 1. 视觉规范（Material Design 3 · 薄荷绿）

本项目应用界面就是 MD3，PPT 跟它保持一致，视觉上"看起来是同一个东西"。

| 角色 | 色值 | 用途 |
|---|---|---|
| Primary | `#146b56` | 标题强调、关键数字、时间轴主线 |
| Primary container | `#c9ece0` | 卡片底、标签底色 |
| Surface | `#fbfdfc` | 页面背景 |
| Surface variant | `#dfeee8` | 表格隔行、图注底 |
| On surface | `#14201b` | 正文 |
| On surface variant | `#43564d` | 次要说明、图注 |
| Outline | `#a8c2b7` | 分隔线、表框 |

- **字体**：中文思源黑体 / 微软雅黑；西文与数字 Roboto，数字用等宽感更强的 Medium 字重。
- **字号**：页面标题 30—34pt；大数字 72—96pt；正文 18—20pt；图注 12—13pt。
- **形状**：卡片圆角 16px，按钮胶囊（999px），不用阴影堆叠（一层即可）。
- **页脚**：左下 `数据库实验 · v1.0`，右下页码 `3 / 10`，10pt，`#43564d`。
- **图片**：等比缩放、**不许裁掉内容**、不放大到模糊；带 1px `#d2e4dc` 描边 + 16px 圆角。
- **留白**：页面左右边距 ≥ 64px；图与文字之间 ≥ 32px。
