## 1. 数字是怎么来的

本章所有数字都能用一条命令复算，不靠人工估算：

```bash
git log --no-merges --numstat --format='@@%an|%ad' --date=short --all
```

统计时不算合并提交（`--no-merges`），因为合并提交本身不产生内容；文件数取该人改动过的去重文件数，
同一个文件改 10 次也只算 1 个；增删行取 `--numstat` 的文本行数，图片这类二进制文件记 0 行，只计入文件数。
