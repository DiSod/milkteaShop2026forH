## 1. 统计口径（先说清楚数字怎么来的）

本章所有数字都能用一条命令复算，不靠人工估算：

```bash
git log --no-merges --numstat --format='@@%an|%ad' --date=short --all
```

- **不含合并提交**（`--no-merges`），因为合并提交不产生内容；
- **文件数 = 该人改动过的去重文件数**，同一文件改 10 次算 1 个；
- **增删行**取 `--numstat` 的文本行数，**图片等二进制文件记为 0 行**（它们只计入文件数）；
- 时间范围截至 **2026-11-09**。
