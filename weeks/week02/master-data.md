## 〇、来源声明与填写说明

### ⚠️ 模拟数据声明（必读）

> 本表以 **蜜雪冰城的产品结构与价格带**为参考 —— 低价带（**2—12 元**）、以**柠檬水 / 果茶 / 珍珠奶茶 / 冰淇淋**为主力品类。
>
> **但配方用量不是任何品牌的真实配方** —— 蜜雪的配方并未公开。用量参照**行业常见区间**取值，**属模拟数据**。
>
> 这一点已在 week1 §5.3「前置风险」第 1 条预留说明："配方数据全为自建，合理性需说明；用量参照行业公开配方区间，并在报告中标注为'模拟数据'"。

### 与 week1 的一处偏差（需小组确认）

week1 §1.1 列的品类是 **4 类**（经典奶茶 / 水果茶 / 纯茶 / 季节限定）。
本草案**增加第 5 类「冰淇淋与奶昔」** —— 理由是低价带奶茶店的冰淇淋是主力产品线之一，且它是**唯一不经过茶底/奶基底**的成品结构，对配方表是一个有价值的对照样本。

### 填写要求

| 项 | 要求 |
|---|---|
| **编号** | 成品 `P0xx`、原料 `I0xx`，**连续不跳号** |
| **单位** | 原料基本单位统一为 `g` / `ml` / `个` / `根` / `张` —— **不做单位换算**（采购也按基本单位记）<br>**散装物料（茶叶、鲜果、糖浆）一律按 `g` / `ml`；只有计件包材用 `个` / `根` / `张`** |
| **用量口径** | 见下文「干重当量」约定 |
| **补货点 / 目标水位** | 当前值为**估计值**，待造数阶段按实际销量校准 |

### 记账口径约定（与 D2 配套）

> **煮制 / 泡制不产生库存流水。**
> 例：干珍珠 100g 煮成熟珍珠 200g —— **不入账**（物料还在店里，只是形态变了）。台账上的"珍珠"数量始终是**干重当量**。
> 因此配方里"珍珠"的用量是**干重**，报损称重后也须**折算回干重**登记。

## 四、配方表（30 款完整配方）

> ### 📌 主数据的唯一真相源声明
>
> **本节的 30 款配方是「主数据（菜单 / 原料 / 配方）」的唯一定义处。**
> 它由 `project/data/generate_seed.py` 的造数数据反填，与 `project/sql/04-seed/seed_data.sql` 的 `tbl_recipe`（**492 行**）逐行一致。
>
> ⚠️ **修改配方一律先改本文件**；`generate_seed.py` 与 `seed_data.sql` **应当由本文件派生**，而不是各自维护一份。
> （这一点已作为连带要求登记在 ISSUE-006 中，见 [`harness/issues/006-sync-schema-design-to-17-tables.md`](../../harness/issues/006-sync-schema-design-to-17-tables.md)。）

### 编排约定

| 项 | 约定 |
|---|---|
| **杯型** | `M`（中杯）/ `L`（大杯） |
| **糖度** | `ANY`（用量与糖度无关）/ `S30` / `S50` / `S70` / `FULL` |
| **`ANY` 的含义** | 该原料用量**不随糖度变化** —— 在库里存为 `sugar_spec_id IS NULL`（见 D-05a） |
| **无糖档** | 🚫 **不写 `NONE` 行** —— 配方中无该行即**用量为 0**（查询时按缺行处理） |
| **用量单位** | 一律使用该原料的**基本单位**（见原料清单） |
| **口径** | **干重当量**；煮制 / 泡制不产生库存流水 |

### 📌 结构样本导览（30 款里的 6 个"边界样本"）

> 30 款配方不是按口味选的，**每个都覆盖一种结构**。其中 6 款刻意承担"边界"角色：

| 成品 | 它补的是哪种结构 |
|---|---|
| **P001 招牌柠檬水** | **最简单** —— 无茶底、无奶基底（水 + 柠檬汁 + 柠檬 + 果糖） |
| **P012 四季春茶** | **纯茶** —— 只有"茶底 + 水"两味原料，**原料数接近下限** |
| **P004 珍珠奶茶** | **经典奶茶** —— 茶底 + 奶基底 + 小料；也是"固定配方与小料两层结构"的例证 |
| **P016 原味奶昔** | **冰淇淋 + 液态，且带糖度** —— 与 P019 形成糖度维度的对照 |
| **P019 香草圣代** | **不适用杯型与糖度** —— 只有 M 杯型，验证"维度不适用"的表达 |
| **P021 脆皮甜筒** | **异形包材** —— 没有杯 / 杯盖 / 吸管 |
| **P022 杨枝甘露** | **原料数上限** —— 6 味原料 + 2 项包材 = 8 条流水/杯 |
| **P027 纯水** | **退化样本** —— 只有纯净水 + 杯 + 吸管 |

> **这 6 个样本的作用**：它们共同证明**配方表不假设任何固定的原料组合** ——
> 从"两味原料"到"八条流水"，从"有杯有吸管"到"只有甜筒和纸套"，同一张表都能容纳。
