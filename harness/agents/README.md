# agents · 子代理任务定义

可委派的**独立任务模板**。用于把边界清晰、能独立完成的工作交给子代理执行，节省主流程的上下文。

## 什么样的任务适合委派

| ✅ 适合 | ❌ 不适合 |
|---|---|
| 边界清晰、可独立完成 | 需要频繁与主流程交互 |
| 产出可结构化校验 | 结论依赖未定型的上下文 |
| 调研、核查、批量生成 | 关键架构决策 |

## 文件格式

```markdown
# <任务名称>

## 目标
一句话说清要产出什么

## 输入
给它的完整上下文（子代理看不到主对话）

## 约束
必须遵守的规范（引用 ../conventions/）

## 产出格式
期望的输出结构

## 验收标准
怎么判断它做对了
```

## 注意

子代理**不继承主对话上下文**，因此提示词必须自包含：把需要的规范、数据、背景一并写入。产出的内容仍需**人工验证**后才可提交（见 `../conventions/05-ai-collaboration.md`）。
