# prompts · 可复用提示词

经实践验证、可再次使用的提示词。一个提示词一个文件，命名 `<用途>.md`。

## 为什么单独存放

课程要求保留提示词作为 AI 使用证据。零散的对话记录难以复用，**整理成模板**后：
- 下次同类任务直接取用，不必重新摸索
- 团队共享，新成员上手快
- 阶段报告里可以直接引用"我们用了哪几个提示词模板"

## 文件格式

```markdown
# <提示词用途>

## 适用场景
什么时候用它

## 提示词
（可直接复制的全文）

## 效果
用过几次、效果如何、有什么坑

## 注意
需要人工检查什么
```

> 提示词在**实际用过并验证有效**之后再收进来；未经验证的草稿留在 `harness/logs/`。

## 注意

提示词中**不要包含**数据库口令、服务器地址、个人手机号等信息（见 `../conventions/05-ai-collaboration.md` 第 8 节）。
