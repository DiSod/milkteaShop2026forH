# logs · 会话与操作留痕

原始会话日志与大段对话的存放处。

## 目录约定

| 位置 | 放什么 | 进 git |
|---|---|---|
| `logs/raw/` | **原始**会话导出、完整对话记录 | ❌ 已 gitignore |
| `logs/`（本层） | **整理后**的摘要、有价值的片段 | ✅ |

## 为什么 raw/ 不进 git

原始会话日志体积不可控（动辄数百 KB 到数 MB），且含大量无用往返。**进 git 会撑大仓库且无法清理历史。**

## 分级存放原则

```
原始对话（体积大、噪声多）        → logs/raw/     不进 git
     │  人工提炼
     ▼
周度 AI 使用记录（结构化）        → weeks/weekNN/README.md      进 git
     │  阶段汇总
     ▼
阶段 AI 使用记录（提交用）        → weeks/submissions/vX.Y/ai-log.md    进 git
     │  提炼成模板
     ▼
可复用提示词                      → harness/prompts/            进 git
```

> **原始日志只是素材**，真正对外的是上层的结构化记录。不要把原始对话直接当作"AI 使用记录"提交。
