# skills · 可复用技能 / 工作流

重复性任务的**固定做法**。与 `prompts/` 的区别：提示词是"一次问答"，技能是"一串有固定步骤的流程"。

## 适用场景举例

| 技能 | 用在哪 |
|---|---|
| 一键重建数据库并验证 | 每次改完 DDL 自检 |
| 从 CSV 生成种子数据 | 第 3 周装载数据 |
| 生成并核对库存台账 | 第 3 阶段事务实验 |
| 生成测试记录 | 第 4 周约束/权限验证 |

## 文件格式

```markdown
# <技能名称>

## 何时用
## 前置条件
## 步骤
1. …
2. …
## 验证
怎么确认做对了
## 常见问题
```
