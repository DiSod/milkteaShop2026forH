## 2. 本轮由 hezhlin5 主责落地（第 11 周 · 触发器体系）

独立落点在 `project/sql/09-programmability/trigger.sql` 与 `test-trigger.sql`（不与 DiSod 已有文件冲突），并接入 `99-rebuild.sql` 与 `regression.sql`（TC-21）：

1. **`trg_stock_ledger_immutable`（`tbl_stock_ledger` `AFTER UPDATE, DELETE`）**：禁止任何角色 `UPDATE` 流水；禁止非 `dbo` 角色 `DELETE` 流水（封堵 `role_manager` 审计销赃口子），并禁止 `dbo` 删除超过 24 小时的历史已结账流水（兼容测试脚本清理刚写入的测试行）。
2. **`trg_points_ledger_immutable`（`tbl_points_ledger` `AFTER UPDATE, DELETE`）**：同上，守护积分审计流水不可篡改。
3. **`trg_order_detail_spec_type_guard`（`tbl_order_detail` `AFTER INSERT, UPDATE`）**：集合级校验 `cup_spec_id` / `sugar_spec_id` / `ice_spec_id` 必须严格属于 `CUP` / `SUGAR` / `ICE`，从库层彻底封堵绕过应用层跳过糖浆扣料的漏洞。
4. **`trg_order_header_state_guard`（`tbl_order_header` `AFTER UPDATE`）**：库层强制订单状态机（终态 `COMPLETED`/`CANCELLED`/`ABANDONED` 不可逆转；禁止非法跳态/回退；流转至 `COMPLETED` 时自动补全 `finish_time`）。
